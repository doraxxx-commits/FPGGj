# FPG V18.5 — Player Career Consequences

V18.5 turns Fame & Reputation into consequences that can change the player's career experience.

## New systems

- Sponsor interest and sponsor tier
- Sponsor income / commercial value
- Agent attention
- Media interview invitations
- Media appearances
- Shirt demand
- Coach pressure caused by public/media pressure
- Fan moments
- Club interest level
- Persistent marketing value

## Causal loop

`World event -> Media -> Fame/Reputation -> Career consequences -> new world events -> Media`

The system is intentionally probabilistic and rate-limited. High fame does not create a sponsor or interview every day.

## Save compatibility

The world save schema is bumped to V6. All new fields have defaults, so older saves remain loadable through the existing migration behavior.
