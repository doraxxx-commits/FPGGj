# FPG V18.9 — Transfer Market UI & Player Decisions

V18.9 connects the V18.8 transfer negotiation engine to the player's actual career UI.

## Core flow

Interest → negotiation → player decision → club negotiations → transfer / rejection.

## Player decisions

- **AKCEPTUJ** — player accepts the current personal package; clubs still need to close the transfer.
- **NEGOCJUJ** — agent sends a counter-position on wage, signing bonus and role.
- **ODRZUĆ** — player rejects the negotiation and the active negotiation is closed on the next world tick.

## UI

`TransfersScreen` no longer generates random fake offers. It reads active negotiations from:

`GameEngine → WorldEngine → WorldSimulation4Engine → TransferNegotiationV2Engine`

The screen displays:

- buyer and seller,
- negotiation round,
- transfer fee,
- wage,
- signing bonus,
- contract length,
- role score,
- current player decision.

## Persistence

The decision is stored directly on `TransferNegotiation`, so it is included in the existing World Simulation save snapshot.

## Compatibility

The new `playerDecision` field defaults to `pending`, so old V18.8 saves remain readable.
