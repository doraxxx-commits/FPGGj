# FPG V11.1C — Youth Career Decisions

V11.1C łączy ścieżkę młodego zawodnika z codziennym życiem rynku.

## Pipeline

`academy -> professional -> first-team candidate -> debut -> first-team / loan candidate -> loan -> external interest -> player decision`

## Nowe elementy

- `YouthCareerProgressionEngine` aktualizuje etap kariery po realnych minutach i występach.
- Po debiucie zawodnik przechodzi na ścieżkę `firstTeam`.
- Długi brak minut + wysoki potencjał prowadzi do `loanCandidate`.
- Wypożyczenie dostaje rzeczywisty termin oparty o absolutny dzień świata.
- `TransferInterestEngine` mocniej uwzględnia młody wiek, ambicję i dopasowanie profilu.
- `PlayerDecisionEngine` uwzględnia minuty, poziom klubu, pensję, gotowość na zagraniczny transfer oraz osobowość.
- Poważne zainteresowanie transferowe tworzy pojedynczy event przy zmianie etapu, bez codziennego spamu.

## Zasada

V11.1C nie zastępuje istniejących silników transferowych. Dodaje warstwę przyczynowo-skutkową, która sprawia, że decyzja młodego zawodnika wynika z jego kariery, a nie wyłącznie z losowania transferu.
