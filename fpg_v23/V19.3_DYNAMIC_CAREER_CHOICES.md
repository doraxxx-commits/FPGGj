# FPG V19.3 — Dynamic Career Choices

V19.3 replaces generic storyline resolution buttons with contextual, stage-aware choices.

## Flow
World event → storyline stage → contextual choices → player decision → consequences → next stage/outcome → media/world event.

Choices depend on storyline type and current stage. Decisions affect happiness, media pressure, fame, reputation, club interest and transfer request state.

The existing V19.2 storyline persistence remains compatible; no new save migration is required because choices are transient and the resulting storyline state is already persisted.
