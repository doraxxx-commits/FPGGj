# FPG V19.8 — Career Relationship Chains

V19.8 builds directly on V19.7. Interactive relationship events can now become multi-stage career stories instead of ending after one answer.

### Added
- persistent relationship chain state
- stage-aware scenes
- delayed follow-up scenes
- coach, agent, club and media chains
- branch-specific consequences for follow-up choices
- save/load persistence for active chains

### Compatibility
Existing V19.7 saves remain readable. New chain fields are optional and default safely when absent.

Flutter/Dart SDK was not available in the build environment, so no local Flutter analyzer or APK build was performed.
