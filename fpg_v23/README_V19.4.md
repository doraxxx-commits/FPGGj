# FPG V19.4 — Relationship Web

Based on V19.3.

New:
- `PlayerRelationships` persistent model
- `RelationshipWebEngine`
- five relationship dimensions: agent, coach, club, fans, media
- decision-driven relationship changes
- daily relationship drift and threshold events
- save/load integration
- Relationship Web career screen

The system does not replace Fame/Reputation or Manager/Team relationships. It is a persistent career-level layer that connects those systems and remembers how decisions changed the player's network.
