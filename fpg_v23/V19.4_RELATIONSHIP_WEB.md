# FPG V19.4 — Relationship Web

V19.4 adds a persistent relationship layer around the player. Five relationships are tracked independently:

- Agent
- Coach
- Club
- Fans
- Media

Relationships drift slowly with the real state of the player and react to contextual career choices. Major thresholds can generate world events such as coach conflict, club tension or media escalation.

## Flow

Career choice -> Relationship Web -> World Event -> Media/Social layers -> future consequences.

The relationship graph is persisted inside `WorldEngine.toJson()` under `relationshipWeb`, so old saves remain compatible and new relationship state survives save/load.

## UI

Career hub now exposes **Sieć relacji**, showing all five relationship scores and recent relationship changes.
