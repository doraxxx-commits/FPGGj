# MATCH ENGINE V7 — Connected Situations

V7 changes the match from isolated events into short connected football situations.

## Situation types

- Build-up: pass -> progression pass.
- Counter: release -> carry -> shot.
- Wing attack: dribble -> cross -> finish.
- Central combination: pass -> through pass -> finish.

A situation is generated by `MatchSituationEngine` and contains ordered beats.
The same sequence can be consumed by the 2D presentation or later by a headless
AI fixture.

## Player interaction

The player's mini-game is only injected when a beat is both relevant and
important. A successful action resolves the current beat and the next beat can
continue on the following match tick. A failed pass/dribble/tackle transfers
possession and naturally breaks the attacking sequence.

## Important limitation

The official league result is still protected by the existing `playFixture()`
contract. V7 improves the causal flow inside the 2D presentation, but the final
migration to a fully emergent official result remains a separate step.
