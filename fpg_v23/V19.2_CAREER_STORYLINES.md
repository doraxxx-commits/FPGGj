# FPG V19.2 — Career Storylines

V19.2 converts isolated career consequences into persistent multi-stage storylines.

## Story types
- Contract Crisis: tension → escalation → ultimatum → player resolution.
- Transfer Saga: interest → media pressure → concrete market option.
- Media Spotlight: recognition → scrutiny → cost of fame.

## Architecture
WorldEngine owns `CareerStorylineEngine`. It observes the same Player/Club state as V18.3–V19.1; it does not create a parallel simulation.

Storylines are persisted through `WorldEngine.toJson()` and restored by `WorldEngine.restoreFromJson()`.

## Player-facing UI
Career Home → Career → Historie kariery.
The Decision Center also links to active stories.

- WYGASZ: reduces media pressure.
- SPRÓBUJ UŁOŻYĆ: improves happiness.

Completed stories remain in a bounded history for career continuity.
