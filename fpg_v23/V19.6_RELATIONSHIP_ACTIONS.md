# FPG V19.6 — Relationship Actions

Based on V19.5.

## Added
- contextual actions unlocked by relationship strength
- coach actions: role discussion and larger-role request
- agent actions: career plan and target-club scouting
- club actions: future/extension discussion and club support
- fan action: support campaign
- media actions: exclusive interview and controlled media reset
- per-player cooldowns with save/load persistence
- direct integration into Career -> Relationship Actions
- actions modify existing Fame, Happiness, Media Pressure, Transfer Pull,
  Club Interest, Agent Attention and Squad Status systems

## Flow
Relationship level -> unlocked action -> player choice -> career state change ->
relationship history -> World Event -> News/Social layers.
