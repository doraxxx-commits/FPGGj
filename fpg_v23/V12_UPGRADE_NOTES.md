# FPG V12 — Match & Living World Upgrade

## Match
- Interactive 2D match is no longer a purely visual replay of a hard-coded score.
- The pre-match score is a baseline; successful player actions can add a decisive goal.
- Goalkeeper mini-games can cancel a pending expected goal.
- The final 2D score is reconciled with the league table exactly once.
- Maximum player-controlled moments reduced to 4 for a cleaner rhythm.

## Mini-games
- Success/failure now has a direct football consequence instead of only a message.
- The match can branch after passes, dribbles, tackles and saves.

## Living world
- Added a state-driven world pulse every few days.
- Financial pressure, board crises, squad atmosphere and youth breakthroughs can create actual state changes and world events.
- These events are based on club/player state, not disconnected fake news.
- Existing autonomous match, transfer, injury, contract, academy and manager systems remain active.
