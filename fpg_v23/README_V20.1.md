# FPG V20.1 — Match Narrative Chains

V20.1 jest rozszerzeniem V19.9. Dodaje trwałe łańcuchy narracji meczowych i zapis ich stanu.

Najważniejszy efekt: pojedynczy mecz może rozpocząć historię, która zostanie rozstrzygnięta dopiero przy następnym występie zawodnika.

Pliki:
- `lib/simulation/match_narrative_chain_engine.dart`
- zmiany integracyjne w `lib/simulation/world_engine.dart`
- `V20.1_MATCH_NARRATIVE_CHAINS.md`

Flutter/Dart SDK nie jest dołączony do tego archiwum; build APK wymaga lokalnego/CI Flutter SDK.
