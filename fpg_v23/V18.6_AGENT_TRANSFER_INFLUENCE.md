# FPG V18.6 — Agent & Transfer Influence

V18.6 makes the agent and transfer market part of the same causal career system.

## Added

- agent market influence grows from fame, reputation, form and transfer pressure,
- agent reputation and negotiation skill affect transfer-market quality,
- club fit is remembered for each interest,
- potential offer quality is remembered instead of recalculated as a random event,
- fame, marketability and agent influence strengthen serious transfer interest,
- transfer requests increase market pressure,
- serious interest can appear earlier when the player has a strong market profile,
- negotiation wages/fees react to the quality of the interest and agent,
- agent portfolios and transfer-interest memory are persisted in saves,
- save schema increased to V7 while old saves remain loadable.

## Causal loop

`Performance -> Fame/Reputation -> Agent Influence -> Club Interest -> Offer Quality -> Negotiation -> Transfer`

The agent still does not force a transfer. The player, club, finances and negotiation system remain authoritative.
